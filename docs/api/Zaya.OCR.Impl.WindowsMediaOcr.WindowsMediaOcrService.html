Remarks

EngineId is windows-media-ocr. Desktop apps typically require package identity (MSIX) to call this API. Install OCR language packs in Windows Settings if recognition languages are missing.

Setting keys

KeyTypeDefaultDescription
languageenum stringauto auto uses OcrEngine.TryCreateFromUserProfileLanguages; otherwise a BCP-47 tag passed to TryCreateFromLanguage. Options include installed OCR languages when available, else All.

Example: 

using var ocr = new WindowsMediaOcrService();
using var session = await ocr.CreateSessionAsync(new Dictionary<string, object>
{
    ["language"] = "en",
});
var result = await session.RecognizeAsync(image);
